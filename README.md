# درس‌بان | منابع و راهبری آموزشی

پیش‌نمایش وب درس‌بان؛ سامانهٔ پیشنهادی برای یکپارچه‌کردن بانک منابع آموزشی، راهبری مطالعه و حمایت از دانشجویان نوورود علوم پزشکی.

این نسخه شامل فهرست درس‌ها، کتابخانهٔ محتوای پیشنهادی، مسیر مطالعه، منتورینگ، حمایت دانشجویی، پیشنهاد محتوا، گردش بازبینی و نمای راهبری است. صفحه‌ها برای دسکتاپ و موبایل چیده شده‌اند و نسخهٔ HTTPS قابلیت نصب به‌صورت وب‌اپ و ذخیرهٔ پوسته برای دسترسی آفلاین دارد.

برای مبنای فهرست درس‌ها و حدود نسخهٔ نمایشی، [راهنمای فارسی](README.fa.md) را ببینید.
