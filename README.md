# درس‌بان | بانک منابع و راهبری آموزشی

پیش‌نمایش گرافیکی و تعاملی درس‌بان، ایده‌ای برای همراهی دانشجویان نوورود همهٔ رشته‌های علوم پزشکی است. صفحهٔ آغاز با اسلایدر تصویری، دسترسی سریع و معرفی مخاطبان، امکانات، چرخهٔ کیفیت محتوا و مراحل اجرای پیشنهادی طراحی شده است.

## مشاهدهٔ پیش‌نمایش

در صفحهٔ آغاز روی «ورود به سامانه» بزنید و از حساب نمایشی زیر استفاده کنید:

- نام کاربری: `darsban`
- کلمهٔ عبور: `darsban1402`

این ورود فقط برای نمایش پنل نمونه در مرورگر است. اطلاعات ورود داخل فایل عمومی سایت قرار دارد و نباید برای حساب واقعی یا اطلاعات خصوصی استفاده شود.

## بخش‌های تعاملی

- صفحهٔ معرفی واکنش‌گرا با اسلایدر، جست‌وجوی امکانات و میانبرها
- فهرست درس‌ها و نمونهٔ رشته‌ای علوم آزمایشگاهی
- بانک قالب‌های محتوایی، مسیر مطالعه و قطب‌نمای برنامه‌ریزی
- پروفایل‌های نمایشی منتورها، حمایت دانشجویی و پیشنهاد محتوا
- گردش بازبینی محتوا و صفحهٔ پایش پیشنهادی

طرح برای نمایش در GitHub Pages آماده است. مبنای فهرست درس‌های نمونه و حدود محتوای نمایشی در [راهنمای فارسی](README.fa.md) توضیح داده شده است.
